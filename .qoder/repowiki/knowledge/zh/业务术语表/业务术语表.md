### DeeWaanAI
- 定义：本项目的主产品名，一个支持多 LLM Provider 编排、Pipeline 构建、团队协作与 Marketplace 的 AI 工作流平台，部署在 Railway（deewaanai-production.up.railway.app），后端 Node.js + MySQL + Redis，前端 React/Vite。
- 别名：DeewaanAI、deewaanai

### Research Mode
- 定义：DeeWaanAI 平台的一个功能开关（feature flag `batch_mode`），允许以批量模式（`run_batch`）并行运行多条 Pipeline 输入，支持状态隔离（stateless）、进度追踪、结果导出，用于支撑学术研究实验的大规模运行。
- 别名：batch_mode、批处理模式

### Pipeline
- 定义：DeeWaanAI 中的可执行工作流定义，由多个 Step（Builder/Critic/Refiner/Polisher 等角色）串联组成，每个 Step 绑定一个 Provider 和具体模型，构成 Agent Team。
- 别名：流水线、管线

### Family（模型家族）
- 定义：实验中按 LLM 供应商划分的模型分组，包括 gpt（OpenAI）、claude（Anthropic）、gemini（Google）、kimi（Moonshot/Together）、qwen（Alibaba），以及 deepseek 作为回退家族。每个家族包含 frontier（旗舰）和 cheap（廉价）两个层级。
- 别名：家族、family

### Frontier / Cheap Sibling
- 定义：每个模型家族内的两个层级：frontier 指该厂商最新旗舰模型（如 gpt-5.6-sol、claude-opus-5），cheap sibling 指同家族的廉价替代模型（如 gpt-5.6-luna、claude-haiku-4-5），用于比较团队编排能否以低成本逼近前沿性能。
- 别名：前沿模型、廉价兄弟模型、frontier、cheap

### Persona（文化人格）
- 定义：注入给 Pipeline 的固定人设文本（congruent mapping），代表不同文化视角，用于测试同一业务问题在不同文化立场下的解决质量差异。分为 N（no persona）和 P（persona）两种 cell。
- 别名：人格、文化人设、cultural persona

### Cell（实验单元）
- 定义：2×2×2 实验设计中的一个组合单元格，由 tier（frontier/cheap）、structure（C-S 单人/C-T 三人团队）、persona（N/P）三因子交叉形成，每个 cell 对应一组固定的 Pipeline 配置。
- 别名：cell、实验单元

### T-EGR（Team Efficiency Gain Ratio）
- 定义：实验的核心因变量，衡量团队编排（3 步 Builder→Critic→Refiner）相对于单人前沿模型在质量和成本上的综合增益，以冻结价格向量计算美元成本，同时记录原始 tokens 保证可复现性。
- 别名：T-EGR、团队效率增益比

### Pilot / Main Run
- 定义：实验的两个阶段：Pilot 用小样本（11 个问题 × 6 cells × 5 families）验证假设并做序贯分析中期检验；Main Run 用 19 个新问题 × 40 pipelines × reps 产生最终数据集（目标 1,900 条运行）。
- 别名：试点、主运行、pilot、main run

### Sequential Analysis（序贯分析）
- 定义：预注册的统计决策规则：在 Pilot 完成后按混合模型 `quality ~ tier * structure * persona + (1|problem) + (1|family)` 做中期检验，根据 p 值和贝叶斯因子 BF₀₁ 决定停止报告、宣告无效或继续主运行。
- 别名：序贯分析、sequential analysis、interim analysis

### Amendment（A1/A2/A3…）
- 定义：对预注册协议的修订文件，记录实验过程中偏离原计划的变更（如模型路由迁移、评判面板替换、分析方法扩展），每个 Amendment 需作者批准并归档，供论文 Methods 披露。
- 别名：修正案、amendment、A1、A2、A3

### Judge Panel（评判面板）
- 定义：由三个互不重叠的模型家族组成的自动化评判系统（最初为 Mistral-Small/GLM-4.7/Llama-3.3-70B，后替换为 DeepSeek/GLM-5.2/Llama），对每个方案给出 1–5 分评分，避免单一评判者偏差。
- 别名：评判面板、judge panel、judges

### AIMD 限流器
- 定义：项目自实现的自适应增量乘减（Additive Increase Multiplicative Decrease）速率控制器，初始 30 RPM、地板 6 RPM、上限 2000 RPM，遇 429/rate-limit 信号减半并发，随后每分钟 +10 缓慢恢复，用于防止压垮上游 LLM 提供商。
- 别名：AIMD、providerThrottle、自适应限流

### Discount Window（折扣时段）
- 定义：某些 LLM 提供商在特定时段提供的降价或加价策略（如 Qwen 北京时区 22:00–08:00 off-peak 折扣、DeepSeek 峰值 2× 加价），实验通过固定执行窗口（14:00–00:00 UTC）规避加价并尽量利用折扣，但成本分析仍以冻结标准价为准。
- 别名：折扣窗口、discount window、peak-valley pricing

### Business Problem（业务问题）
- 定义：实验使用的真实世界商业场景题目，共 30 题（11 个 pilot + 19 个 main），涵盖不同领域，用于评估不同 Pipeline 配置在解决实际商业问题时的表现。
- 别名：业务问题、business problems、BP

### Pre-registration（预注册）
- 定义：学术研究规范：在收集数据前公开声明研究假设、方法、分析计划与停止规则，任何后续变更需以 Amendment 形式记录并获批准，以保证研究的透明度和可重复性。
- 别名：预注册、preregistration、protocol
