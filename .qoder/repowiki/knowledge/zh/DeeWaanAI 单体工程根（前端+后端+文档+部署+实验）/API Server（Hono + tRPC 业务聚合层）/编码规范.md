- 新增业务域以独立 routers/*.ts 文件实现 tRPC 命名空间，并在 router.ts 中集中注册到 appRouter。
- 非 tRPC 的专用 HTTP 端点以 registerXxxRoute(app) 形式在 boot.ts 中集中挂载，便于统一维护。
- 外部依赖（MCP、SSO、Relay）采用 try/catch 包裹注册逻辑，失败时降级而不阻止应用启动。
- 跨模块共享能力统一放在 lib/ 与 infra/ 下，通过单例或工厂函数（如 getDb、getRedis、enqueueSwarmRun）暴露。
- 长耗时任务一律入队至 queue 并由 swarmWorker 异步消费，HTTP 层仅负责提交与 SSE 进度推送。
- 进程级资源（worker、队列、Redis）在 SIGTERM/SIGINT 回调中按顺序优雅关闭，确保在途请求完成后再退出。
