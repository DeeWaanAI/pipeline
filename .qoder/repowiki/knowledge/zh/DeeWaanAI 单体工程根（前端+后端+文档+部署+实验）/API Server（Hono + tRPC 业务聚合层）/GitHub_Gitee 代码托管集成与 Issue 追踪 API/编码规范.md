- 每个 router 入口统一通过 `createRouter({ ... })` 定义，并使用 `authedQuery.input(z.object({...})).mutation/query` 链式声明参数校验与处理逻辑。
- 项目级操作在 handler 内先以 `getDb().select().from(projects).where(and(eq(id, input.projectId), eq(userId, ctx.user.id)))` 校验所有权，再执行 DB 写操作。
- Service 层函数统一以 `getHeaders(token)` 构造鉴权头，并对非 `response.ok` 的情况抛出带状态码的 `Error` 消息。
- `createOrUpdateFile` 采用先 `getFileContent` 获取 sha、再根据是否存在选择 PUT（更新）或 POST（创建）的“先读后写”模式。
- Gitee 路由中对受保护端点统一前置 `if (!(await isFeatureEnabled('gitee_sync', ctx.user.id))) throw new TRPCError({ code: 'FORBIDDEN' })` 的功能开关检查。
- Issue 统计类查询使用 Drizzle 的 `sql\`count(*)\`` 配合 `groupBy` 在服务端聚合，避免将全量记录加载到内存。
