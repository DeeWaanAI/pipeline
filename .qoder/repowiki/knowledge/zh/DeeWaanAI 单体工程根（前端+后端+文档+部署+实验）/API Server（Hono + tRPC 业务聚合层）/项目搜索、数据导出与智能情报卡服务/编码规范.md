- 所有 tRPC 端点通过 `createRouter` 定义，并使用 `authedQuery` / `adminQuery` 中间件统一鉴权，再按需链式 `.input(z.object(...))` 做参数校验。
- 数据库访问统一通过 `getDb()` 获取连接，并按 `userId` 强制过滤（如 `eq(userId, ctx.user.id)`）实现行级所有权检查。
- 导出响应统一附加 `version`、`exportedAt` 字段以支持向后兼容的版本化数据格式。
- 导入操作采用幂等策略：按唯一键（如 agent slug、template name）查重后再插入，跳过已存在记录并返回计数。
- 项目情报卡生成采用分阶段纯函数流水线（extractZip → classify → parseCode/Document → extractDatabaseTables → detectArchitecture/Framework/EntryPoints → assemble），便于单独测试与扩展。
- 大对象输出均设置上限（exports ≤30、entities ≤50、routes ≤30、todos ≤20、relevant files ≤20），防止响应体过大。
