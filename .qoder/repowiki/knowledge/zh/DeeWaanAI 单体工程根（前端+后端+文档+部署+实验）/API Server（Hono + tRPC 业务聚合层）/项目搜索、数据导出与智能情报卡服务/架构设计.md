模块由三个职责清晰的文件组成，均位于 api 层：
- `api/routers/search.ts`：通过 tRPC `createRouter` 暴露单一 `search` 查询，使用 `authedQuery` 中间件校验身份后，对 `projects`、`swarmRuns`、`customAgents` 三张表执行 LIKE 模糊匹配并合并结果。
- `api/routers/export.ts`：集中管理所有数据导出/导入端点，按权限分为普通用户的 `authedQuery`（导出 agents/pipeline/runs/templates、全量备份、导入）和 `adminQuery`（审计账本的 JSON/CSV 导出），后者额外接入 `checkRateLimitAsync` 速率限制并通过 `auditExport` 服务生成 HMAC-SHA256 签名的可验证账本。
- `api/services/projectIntelligence.ts`：纯函数式服务，入口为 `generateIntelligenceCard(zipBuffer)`，内部按阶段处理 ZIP 解压 → 文件分类（code/document/data/config/binary）→ 正则解析代码导出/依赖/TODO → 文档实体抽取 → SQL/Prisma/Drizzle 建表提取 → API 路由识别 → 架构/框架/入口点推断 → 组装 `IntelligenceCard` 并附带 `toLLMContext()` 紧凑文本；另提供 `findRelevantFiles(card, query)` 基于关键词+实体+依赖图 BFS 召回相关文件。
依赖方向单向：routers 调用 services，services 仅依赖本地工具与第三方库（adm-zip），不反向依赖 routers。
