- Stripe 客户端通过模块级单例 `getStripe()` 获取，并在每次调用前用 `isBillingConfigured()` 检查，未配置时抛出 `BillingNotConfiguredError` 以便上层统一降级。
- Webhook 处理采用先 `claimEvent` 插入 `idempotencyKeys` 再执行业务的幂等模式，利用 `ER_DUP_ENTRY` 重复键错误识别已处理事件并返回 `{ received: true, duplicate: true }`。
- 团队席位与个人订阅通过 metadata.type（`team_seats` vs 默认）区分处理分支，避免团队订阅误写入 `subscriptions` 表。
- 订阅状态变更统一经由 `upsertSubscription` + `syncSubscriptionEntitlements` 双写：先落库再调用 entitlements 服务 grant/revoke，保证权限与计费状态一致。
- tRPC 路由使用 Zod schema 定义输入，并通过 `authedQuery` 中间件自动注入 `ctx.user`，未认证或无权限时抛出 `TRPCError`（NOT_FOUND/FORBIDDEN/PRECONDITION_FAILED）。
- 外部 Stripe API 调用失败一律 catch 后记录日志而非向上抛错（如 `syncTeamSeatQuantity`、`cancelTeamSeatSubscription`），确保会员增删等操作不被计费异常阻断。
