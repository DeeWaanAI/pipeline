- 每个路由文件导出一个 `registerXxxRoute(app: Hono<{ Bindings: HttpBindings }>)` 函数，由外部装配器统一挂载，避免在文件顶层直接注册路由。
- 认证采用统一的 `x-local-auth-token` 请求头 + `verifyLocalToken` 解析，再查 `users` 表获取用户信息，未认证一律返回 `{ error }` JSON 并附带对应状态码。
- 对外部输入（JSON body、查询参数、路径参数）先做类型收窄与范围校验，失败时返回带 `error` 字段的 400/401/403/404/413 等语义化响应。
- 数据库操作统一通过 `getDb()` 获取连接并使用 Drizzle ORM 的 `select/insert/update/delete` 配合 `eq`/`and`/`sql` 构建条件，错误通过 `logger.error` 记录后转为 500。
- 需要限流的端点通过 `checkRateLimitAsync` + `RATE_LIMITS` 以 `key:userId|ip` 形式做细粒度节流，并在拒绝时设置 `Retry-After` 响应头。
- 敏感数据（relay token、截图签名）采用哈希或 HMAC 存储/校验，明文 token 仅注册时返回一次，禁止持久化原始值。
