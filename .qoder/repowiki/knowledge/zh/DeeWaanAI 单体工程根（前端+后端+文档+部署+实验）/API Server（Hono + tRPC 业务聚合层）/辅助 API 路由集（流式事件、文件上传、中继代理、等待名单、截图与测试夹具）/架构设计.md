本模块由六个独立的 Hono 路由注册函数组成，每个文件暴露一个 `registerXxxRoute(app)` 函数供主应用挂载，职责边界清晰且互不依赖：
- `stream-route.ts`：通过 `ReadableStream` + `text/event-stream` 向客户端推送 `PipelineEvent`，基于 `eventBus.subscribeClient` 按 `swarmRunId` 订阅并监听 `abort` 清理。
- `upload-route.ts`：接收 multipart 文件，按 MIME/扩展名分类为 image/text/document，分别调用 `pdf-parse` / `mammoth` 提取文本或生成 dataUrl，内置大小限制与 SVG 白名单过滤。
- `relay-route.ts`：实现 Phase 3 on-prem 中继协议，所有 `/api/relay/*` 被 `enterprise_relay` feature flag 中间件统一拦截；提供 register/poll/result/enqueue 四个端点，使用 SHA-256 哈希存储 relay token，并通过 `pending→claimed` 原子更新实现长轮询拉取。
- `waitlist-route.ts`：面向营销站点的公开接口，通过 CORS 中间件允许跨域，对 `join` 做 IP 级速率限制、邮箱/角色校验，并发冲突时返回 409 视为成功。
- `feedback-screenshot-route.ts`：绕过 tRPC 直接处理 base64 图片上传与私有对象存储读取，读路径支持签名 URL 或仅 admin 的本地令牌鉴权，写路径按用户维度限流。
- `test-fixture-route.ts`：仅在非生产环境启用，将 ZIP 文件落盘到 `TEST_FIXTURES_DIR`，通过 `adm-zip` 统计条目数，读写删均绑定当前用户 ID。
所有路由共享 `./queries/connection` 获取 Drizzle 数据库连接、`@db/schema` 类型定义、`./routers/localAuth` 的本地令牌验证以及 `./lib/logger` 日志。
