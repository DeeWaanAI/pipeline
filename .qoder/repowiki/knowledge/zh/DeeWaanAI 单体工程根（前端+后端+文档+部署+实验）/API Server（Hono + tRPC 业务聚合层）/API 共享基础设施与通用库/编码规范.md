- 外部依赖（Redis、S3、Stripe）一律通过 `lib/env.ts` 暴露的配置对象读取，并以空值或默认值实现优雅降级，避免启动期崩溃。
- 可失败的外部服务调用采用 try/catch + logger.warn 记录错误并回退到本地内存实现（如 pubsub 回退到 EventEmitter、Redis 连接失败后标记 gaveUp）。
- 插件以 `PluginManifest` 形式在 `plugins/{id}/index.ts` 中导出，并在 `plugins/registry.ts` 的 `PLUGINS` 数组中集中注册，新增插件只需追加一行。
- 数据库连接使用模块级单例（`getDb`/`getReadDb`），首次访问时惰性初始化并缓存，读写分离通过 `databaseReadUrl` 环境变量开关。
- 日志统一通过 `lib/logger` 输出结构化 JSON 行，级别由 `LOG_LEVEL` 控制，错误走 `console.error`，其他级别走对应 console 方法。
- 测试夹具通过原始 mysql2 直写 SQL 绕过 schema 迁移差异，并提供配套的 cleanup 函数按外键逆序删除数据。
