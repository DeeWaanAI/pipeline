模块由三个职责清晰的文件组成：`api/routers/team.ts` 通过 `createRouter` + `authedQuery` 暴露团队管理端点（创建/加入/列出团队、成员角色变更、项目共享与导入、自定义 Agent 共享等），所有写操作使用 Drizzle ORM 事务保证原子性，并调用 `billingService` 同步座位数；`api/services/sso.ts` 是纯服务端 SSO 库，封装了域名匹配连接查找、OIDC discovery（1h 进程内缓存 + jose JWKS 缓存）、授权码交换（HS256 状态 JWT，10 分钟 TTL）、SAML 响应校验（@node-saml/node-saml）以及按邮箱匹配或冲突安全地 provision 新用户；`api/lib/adminGuards.ts` 抽离出无副作用的防自贬/防删光管理员守卫逻辑，供上层 admin 路由复用。依赖方向单向：router → sso/billing/crypto 等服务，adminGuards 被其他模块引用但不反向依赖 router。
