- 所有 tRPC 端点统一通过 `authedQuery.input(z.object({...})).mutation/query(...)` 链式声明，输入参数用 Zod 严格校验。
- 权限校验在 handler 内部先查 `teamMembers` 表确认当前用户的 role 是否属于 `['owner','admin']`，再执行写操作。
- 对数据库唯一约束导致的并发重复插入采用 try/catch 捕获 `ER_DUP_ENTRY`/`Duplicate entry` 并视为幂等成功返回。
- 涉及多表写入（如创建团队时同时插入 team、member、seat）统一包裹在 `db.transaction` 中以保证原子性。
- SSO 相关外部调用（OIDC discovery、token exchange、JWKS）均设置 `AbortSignal.timeout(10_000)` 防止请求挂起。
- 敏感凭据（OIDC client secret）以密文存储，仅在 token 交换时通过 `decrypt` + `getMasterKey()` 临时解密，不在内存中长期驻留。
