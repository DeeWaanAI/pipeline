- 所有对外路由统一通过 `createRouter` 配合 `publicQuery`/`authedQuery`/`adminQuery` 中间件声明，并使用 Zod schema 对输入进行强类型校验。
- 数据库读写分离：读路径一律使用 `getReadDb()`，写路径使用 `getDb()`，避免误用只读副本写入。
- 权限判定集中在 `entitlements.ts` 的 `can` 函数，按「显式 entitlements → 订阅计划 → tier → voucher」固定优先级顺序解析，新增能力只需扩展 `TIER_CAPABILITIES` 或插入 entitlement 行。
- 对外部不可信 LLM 调用统一包裹 `callWithRetry` 指数退避重试，并通过 `CREDIT_ERROR_PATTERNS` 正则识别配额耗尽错误后立即失败而不重试。
- 盲审任务采用「pooled → assigned → completed」状态机，claim 时使用条件 UPDATE 原子抢占 + 随机排序 + 重复检查，防止并发争抢与同一 reviewer 重复评审同一 prompt。
- 敏感字段（pipeline 步骤、LLM API Key）通过 `cryptoService.encrypt/decrypt` 与 `getMasterKey()` 加解密后再落库/读取，禁止明文存储。
