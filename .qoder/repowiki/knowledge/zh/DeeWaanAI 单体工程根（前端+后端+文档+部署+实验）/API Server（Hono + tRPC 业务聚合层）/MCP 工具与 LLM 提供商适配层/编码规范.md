- 每个 MCP 工具以独立文件导出，统一在 `tools/index.ts` 的 TOOLS 数组中集中注册，并按功能域（pipeline、marketplace、team 等）分目录组织。
- 新增 LLM 提供商需实现 `LLMProviderAdapter` 接口，并在 `lib/providers/index.ts` 的 `createProviderAdapter` 中以 slug 分支返回对应适配器实例，同时在 `getProviderDefaults` 中登记默认 baseUrl 与 supportedModels。
- 工具与服务通过 `McpAuthContext` 传递当前用户/租户身份，所有写操作均基于该上下文进行权限校验。
