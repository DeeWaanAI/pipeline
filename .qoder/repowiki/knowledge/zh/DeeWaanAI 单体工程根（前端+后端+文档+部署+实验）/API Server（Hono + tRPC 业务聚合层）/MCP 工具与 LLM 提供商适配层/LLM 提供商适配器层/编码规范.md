- 每个适配器以工厂函数 `createXxxAdapter(apiKey, baseUrl, defaultModel, config?)` 形式返回 `LLMProviderAdapter` 对象，便于按 slug 动态实例化。
- 适配器内部通过 `config` 注入 `name/slug/defaultBaseUrl/supportedModels`，使同一适配器可复用为多个上游（如 OpenAI 兼容端点承载 DeepSeek、Aliyun、Gemini、Mistral）。
- 错误处理统一在 `formatProviderError` 中按 providerName/status 分支映射为带链接的用户友好提示，再包装为 Error 抛出。
- `chat` 方法首尾记录 `Date.now()` 计算 `latencyMs`，并将各厂商 token 计数归一化为 `promptTokens/completionTokens/totalTokens` 后返回。
- `validateKey` 与 `listModels` 对网络异常或不可用端点做降级处理（返回已知模型列表或最小请求验证），保证上层调用不因上游限制而崩溃。
