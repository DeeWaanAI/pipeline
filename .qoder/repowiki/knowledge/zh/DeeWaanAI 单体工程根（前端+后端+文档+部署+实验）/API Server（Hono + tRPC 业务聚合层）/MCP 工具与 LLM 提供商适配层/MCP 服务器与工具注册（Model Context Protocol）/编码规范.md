- 每个工具以 `McpTool` 对象形式声明，包含 zod 输入 schema、requiredScopes、annotations 与 handler，并由 `tools/index.ts` 统一注册到 TOOLS 数组。
- 新增能力通过可选的 `featureFlag` 字段进行灰度控制，未启用时工具对 `tools/list` 不可见且 `tools/call` 作为未知工具被拒绝。
- 工具调用结果统一包装为 `{ content: [{ type: "text", text: JSON.stringify(result) }] }`，错误经 `McpError` 抛出并由 server 层捕获记录审计日志。
- 所有 I/O 操作（审计日志、用量计数、速率限制）采用 fire-and-forget 异步写入，异常仅记录日志而不影响主流程。
- OAuth 端点严格遵循 RFC 9728/8414/7591 规范，使用 PKCE S256、单使用授权码与 redirect_uri 白名单校验，错误响应统一通过 `oauthError` 构造。
- Session 生命周期由 `transport.ts` 的进程内 Map 管理，带 24h TTL 后台清理，并在 initialize 时将 `sessionId` 与采样桥接注入 `auth.runtime`。
