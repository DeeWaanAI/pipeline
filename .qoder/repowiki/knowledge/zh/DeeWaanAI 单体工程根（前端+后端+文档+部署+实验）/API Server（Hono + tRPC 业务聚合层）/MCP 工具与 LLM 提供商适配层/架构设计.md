本模块由两个协作子层构成：`api/mcp/` 实现 MCP 服务器（server.ts、transport.ts、auth.ts、context.ts），集中注册 `tools/index.ts` 中的 McpTool 列表，并通过 OAuth 2.1 授权与 SSE 传输暴露给外部客户端；`api/lib/providers/` 定义 `LLMProviderAdapter` 统一接口（chat/validateKey/listModels），由 `createProviderAdapter(slug, apiKey, baseUrl, defaultModel)` 按 slug 路由到 openai 或 anthropic 具体实现，并在 `getProviderDefaults` 中维护各厂商默认 baseUrl 与 supportedModels。两层之间的耦合点位于业务服务层（如 routers/llm.ts、services/aiEnsembleReviewService.ts）——MCP 工具不直接依赖具体厂商，而是通过上层服务获取 adapter 实例后再执行业务逻辑，形成「MCP 工具 → 业务服务 → LLM 适配器」的分层调用链，新增提供商只需在 providers 目录添加实现并在 index 中注册即可被所有消费方复用。
