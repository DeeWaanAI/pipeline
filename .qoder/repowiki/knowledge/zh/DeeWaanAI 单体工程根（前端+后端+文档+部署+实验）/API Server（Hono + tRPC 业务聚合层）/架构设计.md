boot.ts 作为单一进程入口：创建 Hono 应用并挂载请求 ID、安全头、body-limit、Sentry 可观测性等全局中间件；随后按职责注册三类端点——(1) 直接 HTTP 端点（流式 SSE、文件上传、Stripe Webhook、备份、等待名单、认证徽章等），(2) /api/trpc/* 下通过 fetchRequestHandler 暴露由 router.ts 聚合的 tRPC 路由树，(3) 可选的 MCP/SSO/Relay 插件路由，失败时自容错不阻断启动。router.ts 将各业务域（project/agent/swarm/marketplace/team/billing/admin/search/integrations 等）以 tRPC 命名空间拼装为 appRouter，并由 middleware.ts 提供的 createRouter/publicQuery 统一注入鉴权、限流、审计上下文。所有子模块（agents_pipelines、teams、billing_webhooks、integrations、marketplace_trust、swarm、admin_audit、search_export、misc_routes、mcp_tools）均依赖 shared_lib_infra 中的 logger/env/Redis/队列/发布订阅/LLM Provider/插件注册/i18n，从而在进程内实现跨域通信；Swarm 流水线执行通过 queue 入队、swarmWorker 消费、SSE 推送进度，并在 boot 中内置 DB-HEAL 与周期性 Reconciler 恢复崩溃残留状态。进程级生命周期由 SIGTERM/SIGINT 触发优雅关闭，依次停止 worker、关闭队列与 Redis。
