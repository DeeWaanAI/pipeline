模块按路由层与服务层分层组织：`api/routers/pipeline.ts` 和 `api/routers/agent.ts` 基于 tRPC 风格的 `createRouter` + `authedQuery` 暴露 REST/GraphQL 风格端点，负责鉴权、参数校验（Zod）与数据库访问；`api/services/batchService.ts` 封装 Swarm 批处理生命周期（创建批次、增量进度更新、取消/恢复、CSV 导出），通过 `enqueueSwarmRun` 将成员任务投递到后台 worker；`api/services/pipelineCreationService.ts` 在 pipelineSteps 已写入后统一补建 `customAgents`、生成可复用 `pipelineTemplate` 并回填 `project.pipelineTemplateId`；`api/services/stateSummarizer.ts` 实现三态记忆（Working/Compressed/Episodic）的压缩策略，通过 `gpt-tokenizer` 估算 token 并按 conservative/balanced/aggressive 模式触发滚动与归档。依赖方向单向：router → service → drizzle-orm schema (`@db/schema`)，并通过 `../queries/connection` 获取 DB 实例，跨服务仅通过函数调用而非共享全局状态。
