- 所有路由端点使用 `authedQuery.input(z.object(...)).query/mutation` 链式声明，输入参数一律经 Zod 校验后再进入业务逻辑。
- 数据库访问统一通过 `getDb()` 获取连接，并使用 Drizzle 的 `eq`/`and`/`inArray`/`asc`/`desc` 组合条件与排序。
- 涉及多表写操作时使用 `db.transaction(async (tx) => {...})` 包裹以保证原子性（如 set pipeline steps、create default pipeline）。
- Agent slug 采用 `${role}-${name.toLowerCase().replace(/[^a-z0-9_-]/g, '')}` 规则生成，并在多处复用该约定进行去重与查找。
- 批量场景优先用 Map 预加载+一次性插入替代 N+1 查询（如 `batchResolveAgents` 中先拉全量用户 agent 再匹配缺失项）。
- 状态持久化采用 Markdown 序列化/反序列化（`serializeStateToMarkdown` / `parseStateFromMarkdown`），字段以 `## Section` 标题划分。
