模块由三个路由层加一个磁盘服务组成：`project.ts` 暴露项目生命周期与 pipeline 配置（使用 `createRouter` + `authedQuery`，通过 Drizzle ORM 读写 `projects`/`pipelineSteps`/`customAgents`/`llmProviders`，并在事务中初始化默认 Builder→Critic→Refiner→Polisher 流水线）；`projectFiles.ts` 实现文件 CRUD 与基于正则的 import/require/dynamic import 解析，将依赖关系写入 `fileDependencies` 表，并提供按路径批量 BFS 的受影响文件分析；`projectImport.ts` 处理 ZIP 导入、调用 `projectIntelligence` 生成 Intelligence Card、可选同步到 Gitee，并通过 `fetchFileContents`/`fetchRelevantFileContents` 实现「先读本地磁盘、再回退 Gitee」的混合读取策略；`services/projectFilesDisk.ts` 是纯文件系统抽象，按 `PROJECT_FILES_DIR/{projectId}/` 目录组织文件，提供 `saveFile/saveProjectFiles/readProjectFile/listProjectFiles/deleteProjectFiles` 等接口，所有路径经 `sanitizePath` 防目录穿越。依赖方向单向：router → services/giteeService & projectFilesDisk，不反向引用。
