- 所有路由通过 `createRouter` 定义并以 `authedQuery.query` / `.mutation` 注册，入参统一用 Zod schema 校验。
- 每个写操作前通过 `eq(projects.userId, ctx.user.id)` 或 `canAccessProject` 进行项目所有权/团队共享鉴权。
- 对第三方外部调用（Gitee API、磁盘 I/O）采用 try/catch 包裹并记录日志，失败时降级而非中断主流程。
- 文件路径在落盘前一律经 `sanitizePath` 规范化并剥离 `../` 前缀，防止目录穿越攻击。
- 数据库写操作集中在 `getDb().transaction` 内执行，确保项目、默认 agent、pipeline steps 原子性创建。
- 大对象（文件内容、intelligenceCard）优先存本地磁盘或 JSON 字段，不在 MySQL 中直接存储二进制内容。
