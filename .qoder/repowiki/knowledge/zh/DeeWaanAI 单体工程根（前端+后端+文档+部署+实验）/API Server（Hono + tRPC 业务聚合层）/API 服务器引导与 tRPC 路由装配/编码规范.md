- 新增外部能力（MCP、SSO、Relay、备份、waitlist 等）通过独立的 `registerXxxRoute(app)` 函数在 boot 中集中注册，失败时用 try/catch 包裹并降级为 404，不阻塞主应用启动。
- tRPC procedure 统一通过 `middleware.ts` 导出的 `publicQuery` / `authedQuery` / `adminQuery` 工厂声明，而非直接调用 `t.procedure`，以保证鉴权链一致。
- 跨请求上下文通过 Hono `ContextVariableMap` 扩展（如 `requestId`）与 tRPC `TrpcContext` 双通道传递，避免在 handler 间透传参数。
- 健康检查与就绪探针分别实现 `/api/health`（仅进程存活）与 `/api/ready`（依赖 DB/Redis 可达），返回结构化 JSON 并以 200/503 区分状态。
