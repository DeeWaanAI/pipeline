模块由四个文件构成应用启动层：`boot.ts` 是进程入口，创建 Hono 实例并注册请求 ID、安全头、body-limit、SSE/上传/MCP/SSO/Relay 等子路由注册器，暴露 `/api/health`（liveness）和 `/api/ready`（readiness）探针；通过 `fetchRequestHandler` 将 `/api/trpc/*` 转发到 tRPC，并在生产环境用 `@hono/node-server` 启动监听端口。`router.ts` 聚合所有业务 router（auth、project、agent、swarm、llm、billing 等）并通过插件注册表 `PLUGINS` 动态挂载，导出 `appRouter` 供 tRPC 使用。`middleware.ts` 基于 `initTRPC` 定义 `createRouter`、`publicQuery`、`authedQuery`、`adminQuery` 等 procedure 工厂，提供角色鉴权中间件。`context.ts` 实现 `createContext`，从请求头解析本地 token、注入 `requestId`/`remoteIp`/`giteeToken` 等上下文字段，被 boot 中的 tRPC handler 调用。依赖方向单向：boot → router/middleware/context → 各 routers/infra，boot 还负责优雅关闭（SIGTERM/SIGINT）、DB 修复与周期性 reconciler 任务。
