模块由三部分组成，职责清晰分层：
- `auth-router.ts`：基于 `createRouter` + `publicQuery` 暴露 `/api/me`（返回当前用户）和 `/api/logout`（本地 token 由客户端管理），属于轻量本地认证端点。
- `sso-route.ts`：通过 `registerSsoRoutes(app)` 将一组 Hono 路由挂载到 `/api/sso/*`，所有端点受 `enterprise_sso` 功能开关门控（禁用时 404，fail-closed），并统一通过 `redirectToLogin` 以 302 携带 `sso_token`/`sso_error`/`next` 跳转回登录页；OIDC 流程（authorize → callback）与 SAML 流程（authorize/metadata/acs）共享 lookup、state 签名校验、连接查找、用户 provision 等能力，全部委托给 `services/sso`；请求来源通过 `x-forwarded-*` 解析，IP 来自 `lib/clientIp`，限流使用 `lib/rateLimiter`。
- `services/tokenService.ts`：独立的令牌服务，使用 jose 的 HS256 JWT 签发/验证访问令牌（issuer=`deewaanai`，key 由 `APP_SECRET` SHA-256 派生），刷新令牌为随机 opaque 字符串并以 SHA-256 哈希形式持久化到 `oauthRefreshTokens` 表，支持按 scope 旋转（旧 token 标记 revoked 后签发新 pair）。
依赖方向：路由层 → `services/sso` / `routers/localAuth` / `lib/*` 工具；tokenService 仅依赖 db schema、jose、env/logger，不耦合 HTTP 框架。
