- SSO 所有路由在入口处统一调用 `flagDisabled(c)` 检查 `enterprise_sso` 功能开关，失败时直接 `c.notFound()` 实现 fail-closed。
- 外部 IdP 交互失败或参数异常一律通过 `redirectToLogin` 以 302 跳转回 `/login` 并附带预定义的 `SsoErrorKey`（config/exchange/state/denied/provision），避免向客户端暴露 500。
- 跨站重定向目标通过 `safeNext` 白名单校验，仅允许以 `/oauth/` 开头的 next 参数透传，防止开放重定向。
- 访问令牌使用 jose 的 `SignJWT`/`jwtVerify` 配合从 `APP_SECRET` 派生的固定密钥，并通过 `ISSUER` 做签发者校验。
- 刷新令牌采用 opaque 随机串 + SHA-256 哈希落库的模式，旋转时先标记旧记录 `revokedAt` 再并发签发新的 access+refresh 对。
