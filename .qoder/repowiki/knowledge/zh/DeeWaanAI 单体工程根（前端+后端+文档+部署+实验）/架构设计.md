根目录作为单体工程的装配层：package.json 的 scripts 同时驱动 vite dev/build（产出 dist/public 静态资源）、esbuild 打包 api/boot.ts 与 api/workerEntry.ts 为可执行产物；vite.config.ts 通过 @hono/vite-dev-server 将 Hono API 与 React 前端在同一个 dev server 上热重载，并以别名 @contracts/@db 把 shared_contracts 与 database_schema 暴露给前后端。api_server 通过 BullMQ + ioredis 消费队列任务并驱动 research_orchestration 的实验流水线，frontend_app 经 tRPC/SuperJSON 调用同一份 Zod Schema 定义的接口。docs_site 独立由 Astro 构建后由 Caddy/Railway 托管，deployment_scripts 中的 CI/CD 与一键部署脚本负责将 dist 与 API worker 发布到生产环境。docker-compose.yml 提供 MySQL 8.0 与 Redis 7 作为共享基础设施，所有子模块通过 .env.example 声明的环境变量接入。
