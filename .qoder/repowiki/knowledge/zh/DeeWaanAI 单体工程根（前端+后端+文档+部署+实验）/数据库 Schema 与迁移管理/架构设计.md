模块以 `schema.ts` 为唯一的数据模型入口，使用 drizzle-orm/mysql-core 的 `mysqlTable`/`int`/`varchar`/`json`/`mysqlEnum` 等 DSL 声明全部表（users、llm_providers、projects、agents、swarm_runs、marketplace_*、teams、feedback、issues 等），并通过 `$inferSelect`/`$inferInsert` 导出 TypeScript 类型供上层 API 复用；`relations.ts` 预留关系定义位置但当前为空。迁移采用 Drizzle Kit 的版本化 SQL 文件（`migrations/*.sql`，按数字前缀排序）配合 `migrations/meta/_journal.json` 跟踪已应用状态，同时保留若干独立 `.sql`/`.cjs`/`.ts` 脚本（如 `add_team_tables.sql`、`migrate-templates.cjs`、`migrate-indexes.sql`）用于一次性或历史遗留变更。`seed.ts` 通过 `api/queries/connection` 获取连接并预留填充逻辑。依赖方向单向：迁移脚本 → schema 定义，应用代码仅依赖 schema 导出的表对象与类型，不直接写原生 SQL。
