- 每个表通过 `mysqlTable('table_name', { ... })` 显式声明列名与类型，主键统一使用 `int('id').autoincrement().primaryKey().notNull()`。
- 外键引用通过 `.references(() => otherTable.column, { onDelete: 'cascade' })` 声明级联删除，避免循环引用时改用应用层校验。
- 枚举字段使用 `mysqlEnum('col', ['a','b','c']).default(...)` 限定取值范围，并在注释中记录业务含义。
- 大文本字段优先选用 `mediumtext`（如 user_prompt、content），长密钥字段使用 `text` 而非固定长度 varchar，以避免溢出。
- 查询索引通过表构造函数的第二个参数 `(table) => ({ idxName: index(...).on(...) })` 集中声明，命名遵循 `idx_<table>_<column>` 约定。
- JSON 字段通过 `$type<{...}>()` 附加 TypeScript 结构，使运行时 JSON 与静态类型保持一致。
