模块以 `main.tsx` 为应用入口，使用 `react-dom/client` 的 `createRoot` 挂载根节点，并依次包裹 `StrictMode`、`ErrorBoundary`、`BrowserRouter`、`TRPCProvider`（集成 `@tanstack/react-query` 与 tRPC 客户端）和顶层 `App`。
- 路由层：`App.tsx` 通过 `react-router` 的 `Routes/Route` 声明所有页面路由，并使用 `React.lazy` + `Suspense fallback={<RouteFallback />}` 实现页面级代码分割；`/login` 重定向到 `Dashboard` 由后者根据认证状态渲染登录表单。
- 布局与导航：`components/layout/AppShell.tsx` 提供侧边栏+主内容区的双栏布局，导航项按 `navSections` 数据驱动配置，支持折叠/展开、当前项目上下文高亮及管理员动态菜单。
- 状态与数据：`providers/trpc.tsx` 集中创建 tRPC 客户端，通过 `httpBatchLink` 调用 `/api/trpc`，使用 `superjson` 序列化并在请求头注入 `local_auth_token`；长耗时操作（如 pipeline 执行）通过 AbortController 设置 10 分钟超时。
- 国际化：`i18n.ts` 基于 i18next + react-i18next，语言与命名空间清单集中在 `i18n-languages.ts`，翻译资源位于 `locales/{en,zh}/*.json`，默认回退语言为 `en`，检测顺序为 localStorage → navigator。
- 共享能力：`hooks/` 提供 `useAuth`、`useCapabilities`、`useSeo`、`use-toast`、`use-mobile` 等跨页面复用的逻辑；`stores/` 用 zustand-style store（`projectStore`、`workspaceStore`）管理全局 UI 状态；`components/ui/` 暴露基础原子组件（button、dialog、card 等），业务组件按领域分目录（feedback、layout、marketplace、pipeline、project）。
- 依赖方向：pages → hooks/stores/providers → components → lib；i18n 资源被 `i18n-languages.ts` 聚合后注入 i18next，不反向依赖业务组件。
