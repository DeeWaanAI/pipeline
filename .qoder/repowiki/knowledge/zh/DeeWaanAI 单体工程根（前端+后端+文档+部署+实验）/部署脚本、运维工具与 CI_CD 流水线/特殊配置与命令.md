`deploy/install.sh` 与 `deploy/aliyun-setup.sh` 需以 root 在阿里云 ECS 上执行，会生成 `APP_SECRET`、`MYSQL_ROOT_PASSWORD`、`MYSQL_SWARM_PASSWORD` 并写入 `/opt/swarm-studio/.env`；`scripts/backup-db.sh` 通过 `DATABASE_URL=mysql://...` 环境变量驱动，默认输出到 `./backups`；`scripts/run-migration-NNN.mjs` 通过 `DATABASE_URL=... node scripts/run-migration-NNN.mjs` 单独执行幂等迁移；`relay/connector.mjs` 通过 `CLOUD_URL`、`RELAY_TOKEN`、`LOCAL_URL` 环境变量启动，无需 npm install。
