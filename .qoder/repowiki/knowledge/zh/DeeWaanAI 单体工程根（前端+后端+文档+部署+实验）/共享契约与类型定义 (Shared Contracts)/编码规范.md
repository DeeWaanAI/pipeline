- 每个数据模型同时导出 zod Schema 与对应的 `z.infer<typeof X>` TypeScript 类型，供调用方进行输入校验与类型推断。
- 枚举型字段统一使用 `z.enum([...])` 定义，并通过 `z.infer` 生成对应联合类型。
- 全局常量（Session、ErrorMessages、Paths）采用 `as const` 对象字面量导出，保证字面量类型精度。
- 错误对象使用带 `tag` 字段的 tagged union 模式，并提供按 HTTP 状态码分类的工厂函数（badRequest/unauthorized/forbidden/notFound/internal）。
