本模块为纯文档仓库，按职责划分为三个子域：
- `DeeWaanAI-Next/` 根目录存放顶层战略与工程规划：`README.md` 定义三产品架构（Companion MCP / Marketplace / TeamSync + Phase 3 Enterprise）与六大设计契约；`FINAL-SPEC.md` 规定 Final Sprint 的 Worker A/B/C/D 分工边界与合并门禁；`PROGRESS.md` 是贯穿 F0 → Phase 0–3 及 Final Sprint 的活清单，每项完成后追加日期与变更文件列表；各 `BATCH-*-PLAN.md` / `*-HANDOFF.md` / `AUDIT-FIXES-BATCH-*` 记录审计加固批次。
- `DeeWaanAI-Next/protocols/` 以两位数字前缀组织研究协议（01–04 为主协议，05–08 为修订 A1–A4，09–12 为 Study2 细化与 Wave Confirmatory Replication），体现版本化协议 + 增补的演进方式。
- `.paper-research/` 仅含 `paperA.txt`、`paperB.txt` 两份研究论文草稿。
依赖方向单向：所有文档互相引用但不被代码依赖，`ACCEPTANCE.md` 作为第三方系统（Stripe、IdP、对端桌面客户端、只读副本）验收的运行手册，独立于实现代码。
