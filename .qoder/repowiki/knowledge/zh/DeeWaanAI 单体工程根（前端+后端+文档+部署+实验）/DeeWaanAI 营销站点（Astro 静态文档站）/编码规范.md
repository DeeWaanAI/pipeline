- 新增语言仅需在 `src/i18n/locales.ts` 的 `LOCALES` 数组中添加代码，并在对应目录下放置 `docs/<locale>`、`blog/<locale>` 内容与 `ui/<locale>.json`，无需修改组件或布局。
- 所有用户可见文案通过 `getUiStrings(locale)` 从 JSON 字符串包读取，禁止在组件中硬编码文本，未翻译时通过 `translated` 标志在 Base 布局顶部显示 fallback 提示条。
- 页面路由统一放在 `src/pages/[...locale]/` 下，使用 Astro 动态段配合 `localeStaticPaths` 为每个已配置语言生成静态路径。
- 内容集合使用 `defineCollection` + zod schema 声明字段类型（title/description/order/date），Markdown frontmatter 必须匹配 schema 才能编译。
- SEO 元信息通过 `Base` 布局的 `jsonLd` 属性集中注入结构化数据（Organization、SoftwareApplication、FAQPage），而非在各页面分散编写 script 标签。
- 构建产物通过 Caddyfile 区分缓存策略：`/_astro/*` 哈希资源设置 `immutable` 一年缓存，其余页面设置 `must-revalidate`，并以 `try_files` 实现 Clean URL 与 404 回退。
